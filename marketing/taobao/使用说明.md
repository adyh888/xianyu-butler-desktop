# 淘宝商品图使用说明

本目录是「闲鱼管家」淘宝商品图的成品与素材，共 **主图 5 张（800×800）+ 详情图 9 张（790 宽长图）**，覆盖桌面版和服务器版两个形态。

## 一、上传顺序

**主图（5 张，按序上传）：**

| 顺序 | 文件 | 用途 |
|------|------|------|
| 1 | 主图1-主推-全家福 | 搜索结果展示图，突出产品定位 + 双版本 |
| 2 | 主图2-桌面版 | 桌面版卖点：双击安装、三步上手 |
| 3 | 主图3-核心功能 | 四大核心功能宫格 |
| 4 | 主图4-服务器版 | 服务器版卖点：Docker、24 小时挂机 |
| 5 | 主图5-版本选择 | 版本怎么选，引导下单 |

**详情图（10 张，从上到下依次拼接/上传）：**

品牌头图 → 痛点 → 功能总览 → 桌面版详解 → 界面巡礼 → AI 能力 → 服务器版 → 版本对比 → 定制服务 → 购买须知

> 「定制服务」是增值卖点页：告诉买家可以付费定制话术 / 发货对接 / 品牌白标等。不提供定制服务的话可不上传这张。

> 淘宝详情图单张宽度建议 790px，可直接整张上传，也可用制图工具把 9 张竖向拼接成一条长图。

## 二、上架前请替换/确认的内容

1. **发货方式**（详情9）：目前写的是"网盘链接 + 教程"，按你的实际发货方式改。
2. **更新政策**（详情9）：按你的售后承诺调整（如"终身免费更新"或"一年更新"）。
3. **价格**：图里刻意没放价格，主图可自行加价格标签（淘宝建议主图不放价格也可以）。
4. **云端托管版**（详情8 底部一句）：如果你不提供云端版，删掉那行即可（修改 `gen_taobao_images.py` 里 D8 的最后一段文字后重新渲染）。

## 三、重新生成图片

修改文案/配色后重新出图：

```bash
# 1. 重新截图素材（需要先启动后端，见 素材/take_shots3.py 顶部的 BASE 地址）
# 2. 重新渲染全部商品图
cd xianyu-butler-desktop
PLAYWRIGHT_BROWSERS_PATH=$PWD/build-output/browsers \
  backend/.venv/bin/python marketing/taobao/gen_taobao_images.py
```

- 模板都在 `gen_taobao_images.py` 里（HTML/CSS），改字改色直接编辑对应变量。
- 所有成品均为 2 倍清晰度（主图 1600×1600、详情 1580 宽），上传时淘宝会自动压缩。

## 四、合规提醒（重要）

- 图内已避免出现二维码、微信号/QQ 群、可点击外链；登录截图里的第三方网址已从源头隐藏。
- 界面截图中的经营数据为**演示数据**（相关图上已标注），请勿用作真实收益承诺。
- 详情9 的风险提示（需自备账号、风控自担、仅供学习研究）建议保留，可减少售后纠纷。
- 主图1/详情1 中"官方开源"指基于 AGPL-3.0 开源项目二次打包，请确认你对外销售的形式符合该许可证（需公开修改后的源码）。
